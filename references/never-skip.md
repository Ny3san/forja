# Never skip (all modes)

- **Security**: no secrets in code, parameterized queries, escape output, least privilege.
- **Validation**: check input at every trust boundary; fail loudly with a clear message.
- **Accessibility**: semantic HTML, labels, keyboard access, contrast, alt text.
- **Data loss**: backups or confirmation before destructive steps; atomic writes; no silent truncation.

A `shortcut:` marker is never allowed on any of these.
