# `/prompt <texto>`

Reescreva um pedido para um agente de código sem inventar fatos nem ampliar o trabalho.

1. Leia `prompt-guide.md`.
2. Identifique resultado, contexto disponível, restrições reais e uma forma de verificar.
3. Consulte o projeto quando ele estiver acessível. Lacunas relevantes ficam como `[PREENCHER: ...]`.
4. Peça plano ou aprovação somente quando houver uma decisão arquitetural, risco, ambiguidade relevante ou expansão de escopo.
5. Se o prompt já estiver específico e verificável, preserve-o e faça apenas ajustes locais.

## Resposta

```text
### Prompt melhorado
<bloco pronto para copiar>

### O que mudei
- <até cinco mudanças com motivo>

### Falta preencher
- <somente lacunas relevantes>

### Vale mover para o AGENTS.md
- <somente informação permanente do projeto>
```

Omita seções vazias.
